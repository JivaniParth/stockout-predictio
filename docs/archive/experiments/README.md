# Historical Experiments Archive

This directory contains legacy exploration scripts from the early development phases.
These scripts are preserved for historical reference and reproducibility audit only.

- `run_dl_85_strategy.py`: Initial exploration of oversampling strategies and deep tabular models.
- `run_dl_enhancement.py`: Early hyperparameter ladder tuning script.
- `run_improvement_ladder.py`: Iterative baseline improvement script.
- `run_experiments.py`: Multi-model architecture comparison script.
- `test_fast_dataloader.py`: Dataloader benchmark probe.
- `run_combined_path1_path2_engine.py`: Path 1 + Path 2 unified exploration script combining Three-Way Decision Policy and Ghazvinian Multi-Objective ANN. Useful logic modularized into `src/scms/models/`, `src/scms/decision/`, and `src/scms/training/`.
